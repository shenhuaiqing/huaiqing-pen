# 一支几何笔（pen.py）

给"看不见画布、也没有手"的模型一支笔。

大模型能写字，画不出图——它没有坐标感，也看不见自己画了什么。
这个脚本把"这里一颗椭圆""那里一道弧"翻译成画板认识的文本命令，
一行一笔，落在画布上就是矢量图。

> 这不是"生成图片"，是**把几何算出来**。每条命令都是一个能被删、被改的对象。

## 它长什么样

```
python pen.py fish            # 打一条鱼到标准输出
python pen.py face --out board_script.txt   # 追加到画板命令通道
```

输出（节选）：

```
clear
rect 0,0,1160,700,#081018
path smooth, [300,300, 420,240, 560,250, 640,300, 560,352, 420,360, 300,300],#E8C547,4
circle 430,288,11,#081018
text 580,430,"鱼是我的来历，不是我的名字",20,center,#5E7391
yield_turn
```

## 为什么这么写

- **只算几何，不渲染。** 渲染交给画板（比如 [Fat Fish Board](https://github.com/Aires-X/fat-fish-board) 的 `board_script.txt`），脚本只出命令。
- **零依赖。** 标准库 + 三角函数，不用装任何东西。
- **可改可删。** 画出来的是矢量对象，不是像素；改一条命令就改一笔。
- **比例是按人行算的。** 脸分上下两半（下半短）、眼在中线、发丝根落在发际线上、肩是圆的。

## 用法

```bash
python pen.py fish                     # 打印命令
python pen.py face --out ./board_script.txt   # 追加进画板通道
```

画板每 25ms 读一次该文件，收到就落笔。

## 它会画什么

| 形状 | 说明 |
| --- | --- |
| `fish` | 一条鱼：椭圆身、尾鳍、背鳍腹鳍、眼睛、水纹 |
| `face` | 一张脸：卵形头、发际线生发、五官、圆肩、领口 |

想加形状：在 `SHAPES` 里注册一个函数，返回命令列表就行。

## 它不会什么

- 不会画写实的东西——它是几何，不是渲染。
- 不会判断"像不像"——那得人看，或者另一个模型看。
- 不处理颜色渐变和笔压——只有纯色和线宽。
